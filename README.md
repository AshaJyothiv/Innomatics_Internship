## Folder Structure

- `Assignment-1` – Web development task given during the internship (HTML/CSS based).
- `Assignment-2` – Follow-up assignment building on layout and styling concepts.
- `Assignment-3` – Task involving more advanced structure / components.
- `Assignment-4` – Final assignment in the series, consolidating previous concepts.
- `HTML_CSS_JS` – Practice files and small exercises in HTML, CSS and JavaScript.
